## [0.6.0](https://github.com/Kuenlun/helioxide/compare/v0.5.1...v0.6.0) - 2026-06-10

### Added

- Add crate-level documentation by embedding the README, whose quick-start example (NREL reference case from appendix A.5) compiles and runs as a doctest, so the docs.rs landing page documents the crate instead of opening on a bare module list. ([#38](https://github.com/Kuenlun/helioxide/pull/38))

### Changed

- **BREAKING:** `SolarPosition::compute` and `SolarPosition::compute_with_delta_t` no longer take a `Surface`, and the `surface_incidence` field is gone from `SolarPosition` (with `Display` no longer printing it). The angle of incidence is now the `SolarPosition::surface_incidence(Surface) -> f64` method, a pure readout of the already-computed `(θ, Γ)` per equation 47, so one computed position serves any number of collector orientations without re-running the pipeline. ([#38](https://github.com/Kuenlun/helioxide/pull/38))
- **BREAKING:** Drop the `calculate_` prefix from every `julian` module function, aligning with the noun-style naming used by the rest of the crate: `julian_day`, `calendar_date_from_julian_day`, `julian_ephemeris_day`, `julian_century`, `julian_ephemeris_century`, and `julian_ephemeris_millennium`. ([#38](https://github.com/Kuenlun/helioxide/pull/38))
- Declare the minimum supported Rust version in `Cargo.toml` (`rust-version = "1.90"`, the const-stabilisation of the `f64` rounding methods used by `helper::int`), verified by building and testing on 1.90. ([#38](https://github.com/Kuenlun/helioxide/pull/38))

### Fixed

- Fix `SolarDay` double-counting `ΔT` in the sunrise/transit/sunset chain: step A.2.2 tabulates `(α, δ)` "at 0 TT", i.e. with the bare midnight JD as the TT epoch, but the three-day tabulation was anchored on `JDE = JD + ΔT/86400` while equation A8 added `ΔT/86400` again through `nᵢ`. The bias was ~0.1-0.25 s on every event (the NREL reference implementation zeroes `ΔT` for this step, `sun_rts.delta_t = 0`). The Table A5.1 assertions now pin transit, sunrise, and sunset to within 50 ms of the published `18:46:04.97 / 13:12:43.46 / 00:20:19.19 UT` instead of the previous 1 s slack that masked the offset. ([#38](https://github.com/Kuenlun/helioxide/pull/38))

## [0.5.0](https://github.com/Kuenlun/helioxide/compare/v0.4.0...v0.5.0) - 2026-05-25

### Added

- Add `delta_t` module exposing `approximate_delta_t_seconds`, dispatching modern-first across the thirteen Espenak-Meeus piecewise polynomial segments covering `-500 ≤ y ≤ +2150` from the *Five Millennium Canon of Solar Eclipses* (NASA/TP-2006-214141), continuing both tails with the Morrison-Stephenson long-term parabola `ΔT = -20 + 32·((y - 1820)/100)²` and blending it into the 2005-2050 quadratic across `2050 < y ≤ 2150` via the canon's `-0.5628·(2150 - y)` linear correction so the hand-off at 2050 joins without a jump. Add `decimal_year` converting a `chrono::DateTime<Tz>` to the Espenak-Meeus year convention (January 1 at 00:00 UT anchored to `year.0`, honouring the proleptic-Gregorian leap rule and propagating sub-second precision) and `approximate_delta_t_seconds_for_datetime` composing the two. ([#31](https://github.com/Kuenlun/helioxide/pull/31))
- Embed the USNO monthly `ΔT` table (Feb 1973 through Apr 2026, 639 samples) in `delta_t`, with `observed_delta_t_seconds_for_datetime` linearly interpolating between adjacent monthly anchors (honouring the Gregorian leap rule via `days_in_month`) and returning `None` outside the published window, and `delta_t_seconds_for_datetime` as the unified entry point preferring the observed value and falling back to the Espenak-Meeus polynomial otherwise. ([#36](https://github.com/Kuenlun/helioxide/pull/36))
- Add the named reference atmospheres `Observer::REFERENCE_PRESSURE_MILLIBARS` and `REFERENCE_TEMPERATURE_CELSIUS` (the equation 42 calibration atmosphere, `1010 mbar` and `10 °C`) and `Observer::ISA_PRESSURE_MILLIBARS` and `ISA_TEMPERATURE_CELSIUS` (the ICAO/ISA sea-level standard, `1013.25 mbar` and `15 °C`, per ISO 2533:1975), promoting the equation 42 literals in `horizontal` to `pub` as their single source of truth. ([#32](https://github.com/Kuenlun/helioxide/pull/32), [#33](https://github.com/Kuenlun/helioxide/pull/33))
- Add fallible constructors `Observer::try_new` (validating latitude `[-90°, 90°]`, longitude `[-180°, 180°]`, finite elevation, pressure `> 0`, and temperature `> -273 °C`), `Observer::try_with_reference_atmosphere`, `Observer::try_at_sea_level_isa`, `Surface::try_new` (validating slope `[0°, 180°]` and azimuth rotation `[-180°, 180°]`), and the infallible `Surface::horizontal` (also wired as `Default for Surface`), alongside per-field `const fn` accessors on both types, the `Observer::TEMPERATURE_FLOOR_CELSIUS_EXCLUSIVE` constant (`-273 °C`, mirroring equation 42's `273 + T` singularity), and the `ObserverError` and `SurfaceError` types via `thiserror`, each carrying the offending value and re-exported from the crate root. ([#32](https://github.com/Kuenlun/helioxide/pull/32), [#33](https://github.com/Kuenlun/helioxide/pull/33))
- Add `SolarPosition::compute_with_delta_t` and `SolarDay::compute_with_delta_t`, the explicit-`ΔT` entry points retained for NREL reference cases and IERS-bulletin overrides. ([#37](https://github.com/Kuenlun/helioxide/pull/37))

### Changed

- **BREAKING:** `SolarPosition::compute` and `SolarDay::compute` no longer take a `delta_t` argument: they now resolve `ΔT` automatically via `delta_t_seconds_for_datetime` (observed USNO value when available, Espenak-Meeus polynomial otherwise). The previous explicit-`ΔT` signatures live on as `SolarPosition::compute_with_delta_t` and `SolarDay::compute_with_delta_t`. ([#37](https://github.com/Kuenlun/helioxide/pull/37))
- **BREAKING:** Make `Observer` and `Surface` valid by construction: their fields are no longer `pub`, so struct-literal construction and field mutation no longer compile. Build through the `try_*` constructors (or `Surface::horizontal`) and read through the accessors. ([#33](https://github.com/Kuenlun/helioxide/pull/33))
- **BREAKING:** Collapse `helper::int` into a non-generic `int(f64) -> f64`. Replace `int::<i32>(x)` call sites with `x as i32`. ([#34](https://github.com/Kuenlun/helioxide/pull/34))
- Loosen dependency version requirements: `chrono` to `"0.4"`, `chrono-tz` to `"0.10"`, and `thiserror` to `"2"`. ([#35](https://github.com/Kuenlun/helioxide/pull/35))

### Removed

- **BREAKING:** Remove the `helper::FromTruncatedF64` const trait and its `const_trait_impl` feature gate, superseded by the non-generic `int`. Replace `int::<f64>(x)` with `int(x)`. ([#34](https://github.com/Kuenlun/helioxide/pull/34))

## [0.3.0](https://github.com/Kuenlun/helioxide/compare/v0.2.0...v0.3.0) - 2026-05-10

### Added

- Add `SpaTimeError::Dut1OutOfRange` and validating constructors `SpaDateTime::try_new` and `SpaDateTime::try_with_dut1` that reject non-finite values and any `|DUT1| >= 1 s` (matching the IERS bound on UT1 minus UTC), plus `datetime()` and `dut1()` accessors and `impl From<DateTime<Tz>> for SpaDateTime<Tz>` as sugar for `new`. ([#7](https://github.com/Kuenlun/helioxide/pull/7))
- Add `heliocentric` module exposing `earth_heliocentric_longitude`, `earth_heliocentric_latitude`, and `earth_radius_vector`, evaluating the Table A4.2 periodic series via Horner's method over SPA equations 9 through 11 with a single `1 / 10⁸` scaling, plus the supporting `helper::limit_degrees` wrapping degrees into `[0°, 360°)` via `rem_euclid` for step 3.2.6. ([#8](https://github.com/Kuenlun/helioxide/pull/8))
- Add `geocentric` module exposing `geocentric_longitude` and `geocentric_latitude` as `const fn`, implementing SPA equations 13 and 14 with `Θ = (L + 180°) mod 360°` and `β = -B`. Promote `helper::limit_degrees` to a `const fn` with a hand-rolled `rem_euclid` so the const evaluator can reach it from `geocentric_longitude`. ([#9](https://github.com/Kuenlun/helioxide/pull/9))
- Add `nutation` module exposing `nutation_in_longitude_and_obliquity`, evaluating the five fundamental angles by Horner's method (SPA equations 15 through 19) and summing the 63-row Table A4.3 in a single sweep with one `sin_cos` per row to fill both `Δψ` and `Δε` accumulators (equations 22 and 23) at half the trigonometric cost of independent passes. ([#10](https://github.com/Kuenlun/helioxide/pull/10))
- Add `obliquity` module exposing `true_obliquity_of_ecliptic`, which evaluates `ε₀` via Horner on `U = JME / 10` against the arc-second polynomial of SPA equation 24 and then returns `ε = ε₀ / 3600 + Δε` per equation 25. ([#11](https://github.com/Kuenlun/helioxide/pull/11))
- Add `apparent` module exposing `aberration_correction` for `Δτ = -20.4898" / (3600·R)` (SPA equation 26) and `apparent_sun_longitude` for `λ = Θ + Δψ + Δτ` (equation 27), summing the two small corrections before adding `Θ` to limit rounding loss. ([#12](https://github.com/Kuenlun/helioxide/pull/12))
- Add `sidereal` module exposing `mean_sidereal_time` (SPA equation 28, with the coupled `JC²` and `JC³` corrections as a single fused product and the dominant linear-in-JD term folded through `mul_add` before wrapping into `[0°, 360°)` per step 3.8.2) and `apparent_sidereal_time` (equation 29, `ν = ν₀ + Δψ · cos(ε)`). ([#13](https://github.com/Kuenlun/helioxide/pull/13))
- Add `equatorial` module exposing `geocentric_right_ascension` returning `α` wrapped into `[0°, 360°)` via `atan2` of SPA equation 30, and `geocentric_declination` returning signed `δ` in `[-90°, 90°]` via `arcsin` of equation 31. ([#14](https://github.com/Kuenlun/helioxide/pull/14))
- Add `hour_angle::observer_local_hour_angle` implementing SPA equation 32 (`H = ν + σ - α`) and wrapping the result into `[0°, 360°)` via `limit_degrees`, with the positive-east sign convention for `σ` documented so a flipped longitude cannot silently shift `H` by `2σ (mod 360°)`. ([#15](https://github.com/Kuenlun/helioxide/pull/15))
- Add `parallax` module exposing `equatorial_horizontal_parallax` (SPA equation 33, returning `ξ` in degrees as the 8.794 arc-second constant divided by `3600 · R`) and `topocentric_equatorial_coordinates` returning the `TopocentricEquatorialCoordinates { right_ascension, declination, parallax_in_right_ascension }` triple from a single call so the geodetic reduction `(u, x, y)` of equations 34 through 36 and the denominator `cos δ - x · sin ξ · cos H` shared by equations 37 and 39 are evaluated exactly once. ([#16](https://github.com/Kuenlun/helioxide/pull/16))
- Add `hour_angle::topocentric_local_hour_angle` as a `const fn` implementing SPA equation 40 (`H' = H - Δα`), intentionally not wrapped into `[0°, 360°)` since the only downstream consumers (equations 41 and 45) read just `sin H'` and `cos H'`, where any signed excursion across the boundary is absorbed by trig periodicity. ([#17](https://github.com/Kuenlun/helioxide/pull/17))
- Add `horizontal` module exposing `topocentric_elevation_without_refraction` (SPA equation 41), `atmospheric_refraction` implementing equation 42's Saemundsson form gated to zero strictly below the cutoff `-(0.26667° + 0.5667°)` per step 3.14.2 (sun-disk radius plus standard horizon refraction), `topocentric_zenith_angle` as a `const fn` fusing equations 43 and 44 into `θ = 90° - (e₀ + Δe)`, `astronomers_azimuth` implementing equation 45 via two-argument `atan2` and wrapping into `[0°, 360°)`, and `topocentric_azimuth_angle` as a `const fn` implementing equation 46 (`Φ = Γ + 180°`) flipping the astronomers' "westward from south" convention into the navigators' "eastward from north" convention. ([#18](https://github.com/Kuenlun/helioxide/pull/18))
- Add `incidence` module exposing `surface_incidence_angle`, which applies SPA equation 47 to combine the topocentric solar position `(θ, Γ)` with a surface's slope `ω` and azimuth rotation `γ`, folding the cross-term inside `mul_add` so the cosine cross-term shares one rounding with the accumulation. ([#19](https://github.com/Kuenlun/helioxide/pull/19))
- Add `equation_of_time` module exposing `sun_mean_longitude` (SPA equation A2 fifth-degree polynomial in `JME` by Horner's method, wrapped into `[0°, 360°)` per step 3.2.6) and `equation_of_time` (equation A1, combining `Δψ · cos ε` and the empirical `-0.0057183°` correction in a single `mul_add`, scaling by `4 min/°`, and folding `±1440 min` once to collapse the residual revolution left over by `M` and `α` having been wrapped into `[0°, 360°)` independently). ([#21](https://github.com/Kuenlun/helioxide/pull/21))
- Add `spa` module exposing `Observer`, `Surface`, and `SolarPosition` value types plus the `SolarPosition::compute` orchestrator running every step from SPA section 3.1 through 3.18 in the order prescribed by NREL/TP-560-34302, with re-exports at the crate root, a `Display` impl rendering every intermediate and final quantity with its paper symbol and units, and a `main.rs` rewired to call `SolarPosition::compute` and print via `Display`. ([#22](https://github.com/Kuenlun/helioxide/pull/22))

### Fixed

- Fix `calculate_julian_day` to honour the effective UTC offset of each civil instant via `chrono::Offset::fix().local_minus_utc` instead of the standard offset alone from `chrono_tz::OffsetComponents::base_utc_offset`, so the forward and inverse Julian Day conversions stay consistent across daylight saving transitions. ([#6](https://github.com/Kuenlun/helioxide/pull/6))
- Fix `calculate_calendar_date_from_julian_day` to build the time of day by adding a `TimeDelta` of whole seconds to `NaiveTime::MIN`, so a fractional day rounding to 86 400 s cascades through day, month, and year instead of producing the invalid `hour = 24` that `Utc.with_ymd_and_hms` would reject. ([#20](https://github.com/Kuenlun/helioxide/pull/20))

## [0.2.0](https://github.com/Kuenlun/helioxide/releases/tag/v0.2.0) - 2026-03-29

Initial release of the `helioxide` crate, a Rust implementation of the NREL Solar Position Algorithm (SPA) covering the Julian Day section of the upstream procedure (NREL/TP-560-34302).

### Added

- Add `julian` module exposing `calculate_julian_day` per SPA equation 4 (with DUT1 correction and timezone normalisation), `calculate_calendar_date_from_julian_day` for the inverse conversion, and the derived `calculate_julian_century`, `calculate_julian_ephemeris_day`, `calculate_julian_ephemeris_century`, and `calculate_julian_ephemeris_millennium` per equations 5 through 8. Restructure the crate as a library plus binary so the SPA routines are consumable from downstream crates. ([#2](https://github.com/Kuenlun/helioxide/pull/2))
- Add `DateTimeWithDUT1` wrapping a `chrono::DateTime<chrono_tz::Tz>` with an optional DUT1 (UT1 minus UTC) correction in seconds, consumed by `calculate_julian_day`. ([#2](https://github.com/Kuenlun/helioxide/pull/2))
- Add `helper::int` and the `FromTruncatedF64` const trait (with `f64` and `i32` implementations) exposing the SPA paper's `INT` truncation operator, plus an `Error` type backed by `thiserror`. ([#2](https://github.com/Kuenlun/helioxide/pull/2))
- Publish to crates.io under `GPL-3.0-or-later` with `description`, `repository`, and `authors` package metadata in `Cargo.toml`. ([#3](https://github.com/Kuenlun/helioxide/pull/3))
